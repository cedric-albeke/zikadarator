## Fixed During This Audit

The Windows CI package path previously diverged from the documented local package and assembled ZIP/installer payloads before signing. It also passed a VST3 bundle directory to `signtool` instead of the plugin binary.

The corrected pipeline now:

1. Signs the VST3 binary and standalone executable before staging when a certificate is present.
2. Fails if a certificate is supplied but signing cannot be completed.
3. Uses `scripts/package-windows-release.ps1` in CI and local packaging.
4. Builds the installer from the same root-level package tree shipped in the ZIP.
5. Records signed/unsigned status inside package build metadata.
6. Checksums the included Inno Setup source.
7. Extracts the final ZIP and runs its checksum verifier before upload.
8. Creates CI build metadata before artifacts are uploaded.

The first UI correctness slice is complete: Presets and Settings now reflow into dedicated rows and two-column control groups, the standalone JUCE device selector is clipped inside a scrolling viewport, chain-badge painting and hit testing share one geometry source, and the duplicate footer `STEP RES` paint call is removed. ## Confirmed DSP And State Gaps

1. `processBlock()` can indirectly resize owned scratch vectors when a host sends a larger-than-prepared block.
2. Same-step host loops or seeks may not retrigger SLICE/LOOP because trigger decisions still lack an absolute transport-cycle identity.
3. LOOP tail labels can exceed the four-second engine history at slow tempos.
4. Several advanced labels overstate their actual DSP; vinyl/scratch remain correctly hidden until a real scrub/resampling model exists.

The first DSP/state slice is complete. `SliceEngine` now receives resolved host/free-clock BPM every block, with separate 60-versus-120 BPM render regressions for free clock and a simulated JUCE host playhead. APVTS is the canonical realtime step-active gate through cached atomic parameter pointers; sequencer metadata, exported snapshot state, StepCell visuals, chains, and header state synchronize without discarding preset or chain data. Factory presets now use JUCE's actual `PARAM` child-tree format, mirror every sequencer gate, and explicitly reset lane mix/mute/solo state, while versioned migration preserves unversioned patterns. Wrong-root host state is rejected before sequencer loading, and state export no longer mutates the live sequencer. Automated Off-to-On transitions inside the current step now have direct behavioral coverage for SLICE retriggering, LOOP history playback, and FILTER reconfiguration. `EnvFollowerEngine` now applies bipolar mapping with direct engine coverage.

Recommended next DSP slice: remove scratch-vector growth from `processBlock()` and introduce an absolute transport trigger identity for host loop/seek retriggering.
